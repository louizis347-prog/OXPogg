# Piloto ilustrado · inglês A1, lições 01–20

Cada lição tem uma cena original produzida para a situação prevista em
`english-a1-plan.js`. As imagens principais estão em `a1-NN.webp` (até 1280 px);
as miniaturas leves da trilha e dos painéis estão em `thumbs/a1-NN.webp`.

Direção visual: desenho editorial inspirado em mangá, com nanquim, hachuras,
expressões humanas e cor aquarelada contida. Não há fotografias nesses vinte
episódios. Textos, áudio, exercícios, identificadores e progresso permanecem
nos dados originais. A lição 21 e os outros idiomas continuam usando a arte
anterior enquanto o piloto é avaliado.

As cenas são composições de cada lição; os recortes nos quadros internos são
decorativos. A capa apresenta uma descrição textual, e as imagens repetidas
nos exercícios usam texto alternativo vazio para não interromper a leitura
por tecnologias assistivas. Os arquivos grandes são guardados no cache apenas
quando a lição é aberta; o catálogo usa as miniaturas.
