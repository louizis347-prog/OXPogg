Perguntas rápidas

É uma série de vídeo?

Não. É uma série interativa, com personagens, balões de conversa, voz e escolhas.

Preciso fazer em ordem?

Recomendamos, porque os personagens voltam. Mas cada episódio funciona sozinho.

Qual a diferença para o Regular?

O Regular parte de obras culturais. O Neighbors parte de conversas do dia a dia.

Pronto para começar?

É grátis para começar. Um só progresso para as cinco experiências.
